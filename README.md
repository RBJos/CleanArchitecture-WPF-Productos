markdown# Productos App - Clean Architecture + WPF + EF Core

App de escritorio con CRUD completo de productos, implementada bajo Clean Architecture.

## 🚀 Stack
- C# / .NET 8
- WPF
- Entity Framework Core
- Clean Architecture (Dominio, Aplicación, Infraestructura, Presentación)
- Async/Await

## ✨ Features
- Crear, Listar, Actualizar y Eliminar productos
- Buscador en tiempo real sin congelar la UI
- Validaciones en capa de Dominio
- Inyección de Dependencias
